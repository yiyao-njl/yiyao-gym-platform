# 体育馆运营管理后台前端开发文档

## 1. 定位

本端是体育馆运营管理系统的 B 端管理后台，目录为 `admin-web/`。后台面向超级管理员、店长、员工，负责经营看板、门店场地、订单、支付退款、用户会员、营销、评价、统计和系统管理。

## 2. 技术栈

- Vue3
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios
- ECharts

本地开发：

```powershell
cd C:\Users\yiyao\Desktop\体育馆运营管理系统\admin-web
npm install
npm run dev
```

默认端口为 `5174`，`vite.config.js` 将 `/api` 代理到 `http://localhost:8080`。

## 3. 目录说明

- `src/main.js`：应用入口。
- `src/router/index.js`：路由表和登录守卫。
- `src/stores/auth.js`：管理员登录态。
- `src/api/request.js`：Axios 统一请求封装。
- `src/api/modules.js`：后台接口聚合。
- `src/layout/AdminLayout.vue`：后台主布局。
- `src/views/`：业务页面。
- `src/utils/status.js`：状态展示工具。
- `src/utils/useChart.js`：ECharts 复用逻辑。
- `src/data/mock.js`：空结构占位，不再作为假业务数据来源。

## 4. 当前页面

- `Dashboard.vue`：首页看板。
- `ResourceManagement.vue`：门店、场地、分类、套餐。
- `Orders.vue`：订单管理。
- `Payments.vue`：支付退款。
- `UsersMembers.vue`：用户会员。
- `Marketing.vue`：优惠券和活动。
- `Reviews.vue`：评价管理。
- `Statistics.vue`：数据统计。
- `System.vue`：系统管理。
- `Login.vue`：管理员登录。

## 5. 接口规则

- 后台接口统一以 `/api` 为 baseURL。
- `request.js` 自动注入 `Authorization: Bearer <token>` 和 `X-Client-Type: admin-web`。
- 后端统一响应 `ApiResponse`，前端只取 `payload.data`。
- 401 时清除登录态并回到登录页。
- 新增接口要同步维护 `src/api/modules.js`，页面不要直接散写 axios 调用。

## 6. 数据与权限约束

- 业务数据必须来自后端接口，接口失败时展示 loading、空状态或错误提示，不展示假数据。
- 默认开发账号来自 MySQL `admin_account`：`admin / admin123`、`manager / admin123`、`staff / admin123`。
- 后续生产需改为 BCrypt 密码、真实角色权限和操作日志审计。
- 金额、订单状态、支付状态、退款状态只展示后端结果，前端不能自行改写最终业务状态。
- 危险操作必须二次确认，并由后端记录操作日志。

## 7. 开发检查清单

1. 新增页面时同步添加路由、菜单和权限控制。
2. 新增接口时同步更新 `modules.js` 和后端网关路由。
3. 表格页必须覆盖 loading、空状态、错误状态和分页。
4. 图表页复用 `useChart.js`，避免重复初始化逻辑。
5. 打包前运行 `npm run build`，确认没有语法和资源路径错误。
